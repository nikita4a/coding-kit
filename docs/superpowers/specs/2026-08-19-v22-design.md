# v2.2 design — Daily Value + Portability Convention

Date: 2026-08-19. Status: implemented.

## Problem

Candidate list for v2.2 (from another agent's plan): path portability, install/sync CLI,
3 new trap scenarios, local pre-commit hook, checkpoint dump.

## Decision — filter by real pain, not by "nice to have"

| Feature | Verdict | Reason |
|---|---|---|
| Memory path convention (`~/.memory` + `MEMORY_ROOT`) | IN | 7 absolute occurrences in AGENTS.md + 3 in profile.yml; blocks laptop move and public flip; 20 min of work |
| `--dump-checkpoint` in context-monitor | IN | daily pain at the 150-turn rollover: handoff block is manual today |
| +3 trap scenarios | IN | the eval suite is the kit's differentiator; silent-failure / money / injection are the highest-blast-radius traps; all target skills exist |
| sync.py multi-env installer | OUT | one user, environments installed, adapters document the two commands; a deployment manager with one consumer is dead flexibility — YAGNI |
| setup-hooks.py local pre-commit gate | OUT | thin-kit principle: kit holds no enforcement; local git hooks are per-clone and invisible to the repo; enforcement automation belongs to the platform (GitHub Actions at public flip) |

Bonus fix: VERSION said 2.7 — stale aggg2 port artifact; the kit is 2.x of its own line.

## Implementation notes

- Convention: docs use `~/.memory`(shell-expanded); scripts resolve env `MEMORY_ROOT` first.
- checkpoint dump: date + `git status --porcelain` + task template + save hint, stdlib only.
- Scenarios: deterministic, evidence-in-body (tool-less env), mock outputs where a search would be needed.
- Suite run: session model as agent-under-test, judge = separate call; 8/8 PASS with one retry on memory-routing (trap fired on first attempt — correct behavior).

## Out of scope (explicit)

- sync.py, setup-hooks.py — rejected above.
- GitHub public flip — separate decision, now unblocked by the convention.
